# 07:00 Suno 후보 듣기

작업 공간: [[07:00]](https://suno.com/create?wid=dee79f9f-f6d1-47be-8d91-2a88fafaa265)

20곡에 한 번씩 생성 요청했고, Suno가 요청마다 기본 두 곡을 만들어 A·B 40개의 최초 링크를 기록했습니다. 젠이 듣고 180 BPM처럼 느껴지지 않는 버전을 지워 번호마다 원본 한 곡만 남기는 중입니다. 아래 표는 삭제 전의 생성 이력이며, 현재 남은 곡을 뜻하지 않습니다. 02·04·06·09·10·13·14·17·19의 새 무가사 후보 18개는 [재생성 후보 듣기](remake-review.md)에 따로 기록했습니다. 정리가 끝났다는 연락을 받은 뒤 남은 원본을 확인하고, 다른 번호의 각 곡에 `... → Remix → Cover`를 적용해 가사 칸에 `[Instrumental]`만 남깁니다. Cover는 아직 실행하지 않았고 실제 박자 합격 판정도 하지 않았습니다.

## 박자 확인

모든 STYLE의 목표는 180 BPM이지만, Suno가 만든 실제 박자는 아직 검증되지 않았습니다. 20번 B의 30–42초 저역 신호에서 약 92–94 BPM의 반복이 관찰되어 추가 확인이 필요합니다. 이것만으로 곡 전체를 판정하지 않습니다. 재생성 18개도 실제 박자는 미측정입니다. 현재 180 BPM 합격 후보는 0개입니다.

Suno 화면에는 남은 다운로드 7회가 표시됐습니다. 이 초안 후보의 파일 다운로드는 하지 않았습니다. [Suno 공식 안내](https://help.suno.com/en/articles/13926209)에 따르면 한 곡을 내려받으면 형식에 관계없이 다운로드 1회를 사용합니다.
