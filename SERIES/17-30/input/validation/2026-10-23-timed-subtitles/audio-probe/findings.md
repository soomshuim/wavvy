# 17:30 한국어 자막 음향 시험 결과

2026-10-23. 원본 WAV를 실제로 청취하지 않았다. 아래의 가창 내용과 단어 시각은 무프롬프트 로컬 음성 모델의 **독립 전사 추정**이며, 사람이 들은 사실로 적지 않는다. 원고는 변경하지 않았다. 모든 시각은 각 곡 WAV 시작을 0초로 한 값이다. 원본과 자동 자막의 상세 문맥은 [약한 8행 원자료](weak-eight-source-context.md), 모델의 전 단어·확률은 같은 폴더의 `*-whisper.json`에 있다. 손실 없는 시험 클립은 [작업 폴더](../../../../work/2026-10-23-timed-subtitles-audio/clips)에 보존했다.

## 방법과 한계

- 원본 WAV에서 FFmpeg로 필요한 구간만 16 kHz 모노 FLAC으로 분리했다. `mlx-whisper` 0.4.3과 `mlx-community/whisper-large-v3-turbo` FP16을 격리 가상환경에서 실행했다. `language=ko`, `temperature=0`, `condition_on_previous_text=False`, `initial_prompt=None`, `word_timestamps=True`였다. 가사 원문을 모델에 힌트로 넣지 않았다. 모델은 [공식 MLX Whisper 사용법](https://github.com/ml-explore/mlx-examples/blob/main/whisper/README.md)의 로컬 경로로 사용했다.
- Whisper의 단어 시작값은 바로 앞 단어의 끝이나 무음으로 당겨질 수 있다. 따라서 아래의 시각은 대략적 위치 확인용이며, 기존 SRT 시작 시각을 일괄 대체할 근거가 아니다. 낮은 확률, 원고와 다른 문구, 클립 끝 부분의 출력은 특히 조심해야 한다. 첫 곡 37초 시험에서 원고 1–7행은 실용적으로 인식했지만, 8행 자리에서는 `오늘의 영상은 정말 좋습니다.`라는 환각이 나왔고 첫 단어 확률은 0.032였다. [원시 출력](first37-whisper.json).
- 선행 한국어 CTC 강제 정렬 시험은 전곡 적용에서 제외했다. 첫 곡 4행은 31초/37초 시험에서 14.389/14.388초, 7행은 26.317/26.314초로 안정적이었으나, 8행을 실제 문구보다 앞선 28.315초에 배치하고 평균 토큰 점수가 -7.469였다. 자유 전사도 알아보기 어려운 글자열이었다. 원고 `잠깐`의 `깐`은 이 CTC 어휘에 없어서 시험 입력만 `잠간`으로 바꿨다(`깐`→`간`, 원고 출력은 그대로 보존). 이 정규화 뒤 미상 토큰은 없었다. [31초](first31-ctc.json), [37초](first37-ctc.json) 원시 결과 참조. 같은 모델은 노래가 있는 창과 자동 자막 공백 창 양쪽에서 임의 한글을 출력했다. 따라서 50–69초, 107–126초를 간주나 추가 가창으로 판정하지 않았다. [공백 시험](gap-asr.json).

## 전곡 20개 독립 전사 인계

같은 모델·고정 파라미터로 원본 WAV 20개를 전사했다. [전곡 원시 JSON 목록·해시·시간 기준](full-track-whisper-manifest.json)에 각 파일이 있다. 각 JSON 이름은 원본 WAV의 `.wav`를 `-whisper.json`으로 바꾼 형태다. 20개 오디오의 SHA-256은 `output/report.json`과 모두 일치했고, 총 3,874.85초 오디오의 모델 추론 시간 합계는 140.472초였다. 11곡을 제외한 19곡 일괄 실행의 실제 경과 시간은 134.994초, 전곡 원시 JSON 합계 크기는 약 0.822 MB다.

JSON의 `segments[*]`와 `words[*]`는 각각 **원본 WAV 시작 0초 기준**이다. 영상 속 위치는 매 곡의 실제 시작을 더한다. `output/report.json`에 기록된 WAV 길이를 단순 누적하면 곡 사이 0.8초 겹침이 누적되어 틀린다. 인계 목록의 `video_pass_1_start_ms`는 기존 문자 정렬 자료의 첫 재생 시작 오프셋을 그대로 기록했다. 예를 들어 11곡 시작은 1955.26초로, WAV 길이 단순 누적 1963.26초보다 8.0초 빠르다. 두 번째 재생은 별도 시작 오프셋을 적용해야 한다. 전곡 전사는 실제 반복 구조 비교의 자료이지, 원고 글자·SRT 시각을 자동 대체하는 근거가 아니다. 음악만 남는 끝부분에는 그럴듯한 환각 문구도 있다.
