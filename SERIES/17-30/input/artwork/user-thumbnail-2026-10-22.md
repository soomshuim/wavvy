- 출처: 젠이 `SERIES/17-30/input/thumb.jpg`를 첨부하며 “내가 직접 만들었어.”라고 했다. 이 파일을 현재 썸네일 기준본으로 사용한다.
- 현재 파일: `SERIES/17-30/input/thumb.jpg`
- 실측: JPEG, 2532×1424, 1,441,407 bytes, SHA-256 `634cbb9ff89b2c39cf89a240100368b310c0e22bfaee60a0463170f25912e025`.
- 보이는 글자: 흰 Wavvy 로고와 `17:30`, 큰 가는 영문 `RE-FRESH`. 글자의 위치·색·폰트는 젠이 만든 파일 그대로 둔다.
- 구 합성 `thumb.jpg`의 SHA-256은 `aa875945206a48b7ba5fd24edb562e4544ff0a4673fdf53d3c9cc1b417705b4c`였으며 Git 이력에 남는다. 승인된 v5 장면의 `input/loop.png`도 기존 SHA-256 `e27ade02cc17e58bceb7d9fbe6502e1ced62613cded357e59ffe58842dc68ca7`로 보존한다.
- `input/artwork/thumb.psd`(17,535,068 bytes, SHA-256 `939f5005b24aa1953b3ad1418bff46b5dd189866c090d93b92fec3bcf2d9f0a5`)는 사용자 편집 원본일 수 있어 로컬에 보존하고 Git 추적에서 제외한다. 파일 작성자를 별도로 검증한 것은 아니다. 폴더 이동 직후보다 바이트가 바뀌었으므로 이동 후 사용자 편집 가능성이 있는 최신 파일로 다룬다.
- 영상 배경 `input/loop.png`: 3840×2160, 4,584,887 bytes, SHA-256 `e27ade02cc17e58bceb7d9fbe6502e1ced62613cded357e59ffe58842dc68ca7`. 승인된 v5 장면을 Lanczos로 확대했으며 원생성 4K는 아니다. 현재 사용자 썸네일과 배경의 픽셀 동일성을 주장하지 않는다.
- 작업자 수정 시안 v2와 새 이미지 생성 v3는 채택하지 않은 이력이다. 젠의 현재 썸네일은 이 둘에서 자동 합성한 결과가 아니다. 젠의 “안쓰는 썸네일 이미지와 프롬프트 파일 싹 삭제해.” 지시로 프로젝트 안 미사용 파일 15개를 [상대경로·SHA·크기 목록](../validation/2026-10-22-unused-thumbnail-deletion.json)에 남기고 삭제했다. 이 메타에는 삭제한 프롬프트 본문을 복사하지 않았다. 영상 제작은 아직 시작하지 않았다.
