## Series DNA

**기분 좋은 POP(Main) R&B.**

RNB-BEST가 기존 R&B 계열 베스트 컴필레이션이었다면, 이 시리즈는 새로 만드는 메인스트림 Pop R&B 시리즈다.
R&B의 부드러운 보컬과 코드감은 유지하되, 첫 청취에서 바로 밝고 쉽게 들어오는 팝 접근성을 우선한다.
시간대는 17:00. 퇴근길 위로를 다루는 18:00과 달리, 퇴근 직전부터 기분을 먼저 끌어올리는 밝은 전환의 시간이다.
단, 이 시간대는 사운드 포지셔닝이다. 가사가 17:00, 퇴근, 사무실, 업무를 직접 다룰 필요는 없다.

### Sound Identity

- **Mood**: bright, uplifting, breezy, confident, easy to replay
- **Genre Lane**: Main Pop R&B / Contemporary R&B / Light Funk Pop / Urban Pop
- **Energy**: mid-up to up-tempo only
- **Groove**: clean bounce, light funk guitar or bright synth accents, tight pop drums
- **Vocal**: polished Korean vocal, clear melodic hook, easy chorus memory
- **Use Case**: 퇴근 시간대 기분 전환, 낮-저녁 사이 드라이브, 카페, 쇼핑몰/매장, 작업 마무리 환기

### Hard Gates

| Gate | Rule |
|---|---|
| BPM | **120 BPM 이상만 허용** |
| Key | **Major key only**. Minor, modal minor, dark ambiguous key 금지 |
| Mood | 밝고 기분 좋은 톤. 우울/새벽/이별 침잠 중심 금지 |
| Hook | 한 번 듣고 기억되는 melodic chorus 필수 |
| Mix | 깨끗하고 메인스트림한 pop mix. lo-fi/raw/demo 질감 금지 |
| R&B DNA | Rhodes/EP/chord color, smooth vocal phrasing, groove pocket 중 최소 2개 이상 유지 |

### Do

- 밝은 Major chord progression을 쓴다.
- chorus는 더 팝적으로 열고, verse는 R&B 포켓을 살린다.
- 120-132 BPM 중심으로 산뜻하게 유지한다.
- guitar chop, clean synth pluck, bright EP, slap/round bass를 활용한다.
- 한국어 가사는 가볍고 선명한 일상 감정으로 둔다. 시간/퇴근 소재는 필수가 아니다.

### Do Not

- 119 BPM 이하 금지.
- Minor key 금지.
- 느린 발라드, 수면 전 R&B, dark trap R&B, 새벽 감성 금지.
- 과한 neo-soul 전개, 어려운 코드 진행으로 메인 팝성을 흐리지 않는다.
- idol chant, EDM drop, big-room build, hyperpop 과잉 질감 금지.
