# 19:30 — 현재 6곡에서 20곡으로 확장하는 신규 14곡 설계

상태: **젠의 “생성해.” 승인으로 07~20 신규 독립곡 14개를 각 1회 생성해 28후보가 모두 화면상 완료됐다. 기존 6곡을 보존한 총 34개·140크레딧 사용(1506→1366)·최종 14곡 선택 대기.** 기존 탈락곡은 복원하지 않는다. 이 요청은 일반 문장으로 받은 직접 확장 지시이며 `-wavvy-produce`를 실행한 기록이 아니다.

사용자 원문: “지금 6종을 기반으로 20곡으로 확대하자. 다만 코드 진행이나 악기스타일은 비슷한게 반복되지 않도록 베리에이션 치고 스타일도 잘 섞어줘.”

## 기준과 한계

- 선례: [현재 6곡 문구 비교](../reference/six-tracks-style-profile.md), [최신 6곡 원문](../../../.ai/research/2026-10-26-1930-six-tracks/refresh-01/current-styles-verbatim.txt). In Da Dream·점층형 3곡의 여백, Pulse의 칩 음색, Sunlit의 베이스/록 브레이크를 교차 사용한다.
- 기존 6곡의 실제 코드 진행은 확인되지 않았다. 아래 조성·코드는 **새 곡의 제작 목표**이며 원곡 채보나 실제 생성 결과가 아니다. 기존 6곡과 진행이 다르다고 실측 주장하지 않는다.
- 전곡 무가사·120~128 BPM·4/4. 바탕 선율과 게임 건반 훅은 아주 단순하고 음 수가 적다. 반복되는 훅의 음 수·장식·속도를 늘리지 않고 화음·음역·드럼·공간으로 성장시킨다. 긴 16분음표 아르페지오나 여러 대선율을 지시하지 않는다.
- 감정 3축은 **슬픔 / 밝은 온기 / 추진력**이며 1은 낮음, 5는 높음이다. 청음 실측 점수가 아닌 설계값이다. 코드 한 개를 1~2마디 이상 유지해 화성 다양화가 연주 복잡화로 번지지 않게 한다.
- 영어 제목 14개는 작성 전 SERIES의 md/txt 검색에서 동일 문구 0건이었다. 기존 입력·6곡 원문·concept 최종 소스는 수정하지 않는다.

## 중복을 줄인 근거

- 같은 음 하나의 8마디 독주는 **07·10·14·17, 4곡**에만 적용한다. 나머지 10곡은 베이스, 드럼, 두 음, 화음, 합주 또는 훅에서 다르게 시작한다. 같은 계열이 길게 연속되지 않도록 배치했다.
- 14개 로마숫자 진행은 서로 다르다. 시작점만 돌린 순환형과 실제 코드의 반음 간격·장단 성질을 함께 비교해 단순 이조한 순환도 중복 0건을 확인했다. 코드를 2~4개로 제한하고 곡별로 유지 길이를 다르게 둔다. D Minor의 G Major, G Major의 Eb Major 등 비다이아토닉(조성 밖에서 빌린) 화음은 의도한 색이며 오기가 아니다.
- 특정 한 악기만 14번 복제하지 않고 주선율 음색과 화음 받침을 분리했다. 칩/디지털 건반이라는 공통 축은 유지하되 오르간·피아노·기타·얇은 현악·신스 받침을 교차한다. 완전히 같은 주요 악기 조합은 없다.
- 이 표의 악기·코드·감정은 제작 제안이다. 문구가 실제 음원을 보증하지 않으며 생성 뒤 청취와 사용자 선택이 필요하다.

## 파일 및 검사 상태

매트릭스 초안을 먼저 저장했다. 07~20 txt 14개를 작성했고 각 파일의 실제 `track-prompt` 검사는 **14/14 PASS, 모두 exit 0**이다. 본 검사는 글자 수·필드·무가사 태그를 확인하며 실제 음악의 다양성이나 길이를 인증하지 않는다. 별도 전체 가사를 쓰지 않으므로 `lyrics-review --mode full-lyric-draft`를 실행한 것으로 기록하지 않는다.

### 최종 형식·분포 확인

- STYLE: **753~836자 / 900자**. Exclude: **7~8항목 / 최대 8항목**. 전곡 `Vocal: Instrumental`과 LYRICS의 `[Instrumental]`만 사용한다. 숫자 BPM·조성은 각 STYLE과 메타데이터가 일치한다.
- 로마숫자 순환 이동 중복 **0건**. 실제 코드의 시작점을 바꾸고 같은 간격으로 이조했을 때도 같은 장단 성질의 순환 중복 **0건**. 끝·처음의 같은 코드가 붙은 경우 하나로 줄여 비교했다. 진행을 역순으로 뒤집는 것은 같은 순환으로 취급하지 않는다.
- 고유 화음 수: **2개 2곡(15·17), 3개 4곡(08·09·14·20), 4개 8곡**. 한 코드 유지 길이는 곡별 1~4마디다. 13의 최종 진행은 **Eb–Gm–Cm–Fm, I–iii–vi–ii, 코드당 1마디**다.
- 공통 주선율은 단순한 게임/디지털 건반이다. 화음 받침 악기 분포는 **기타 5, 오르간 2, 피아노 2, 신스 2, 얇은 현악 2, 클라비 1**이다. 완전히 같은 주요 악기 조합 0쌍, 같은 드럼 설명 0쌍이다. 이 수치는 설계 문구의 분포이며 실제 음색을 분석한 결과가 아니다.
- 조성은 Major 8곡·Minor 6곡, BPM은 120~128이다. 슬픔을 중심으로 둔 곡과 밝은 온기·추진력을 중심으로 둔 곡을 교차했다.
- [기계 대조 원시 결과](../../../.ai/research/2026-10-26-1930-expansion/validation.json), [곡별 gate 원문 폴더](../../../.ai/research/2026-10-26-1930-expansion/gates/), [gate 요약](../../../.ai/research/2026-10-26-1930-expansion/gate-summary.json). 검토 판정은 이 형식 결과와 별개다.
- 사용자 승인 원문은 **“생성해.”**다. **14곡 각 1회 생성 완료·28후보**, 기존 6곡을 보존한 총 34개이며 누락·추가 ID는 없다. 이용량은 **1506→1366, 140크레딧**이다. [듣기 목록](expansion-listening-list.md)에서 최종 14곡 선택을 기다린다. 신규 화면 길이는 **1:50~3:45**이며 일부는 목표보다 짧다. 재생 버튼 활성 표시를 확인했지만 직접 청음·재생은 하지 않았다. concept의 최종 소스 승격·state 재생성·커밋·푸시는 수행하지 않았다.
