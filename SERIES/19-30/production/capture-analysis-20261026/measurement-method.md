# Current20 파형 측정의 범위와 해석

이 자료는 최종 곡 순서가 아니다. Goodbye 1번 고정은 사용자 결정이다. 직접 청음은 수행하지 않았다. 브라우저 재생·녹음 제어와 원본 수정은 수행하지 않았다.

- 입력은 녹음 담당자가 닫힌 파일과 검증 완료를 알린 시도뿐이다. 각 `analysis.json`의 원본 SHA-256은 해당 `capture-verification.json` 및 독립 반복주기 결과와 일치한다. 실패·미완료·진단 녹음은 제외한다.
- 곡 범위는 UI 재생 시계와 캡처 PTS(오디오 버퍼의 시각 기록)를 맞춘 추정값이다. 녹음 앞뒤 대기 시간과 곡 안의 도입·여백을 구분한다. 오디오 출력 지연은 보정하지 않았으므로 연결 초 단위 값이 실제 들리는 첫 박자를 정밀 보증하지 않는다.
- 파형·에너지·스펙트럼은 보존한 곡 범위 전체에서 측정한다. 22,050Hz로 바꾼 분석 신호에서 STFT(짧은 구간별 주파수 분석) 2,048샘플, 간격256샘플을 쓴다. 원본은48,000Hz 스테레오 float32 그대로다. 분석용 오디오 파일을 따로 만들거나 도입·끝을 잘라내지 않는다.
- 음색 수치는 centroid(주파수 밝기의 중심),20–250Hz 저역 비중,2kHz 이상 고역 비중 등이다. onset(짧고 급한 소리 변화) 밀도는 각 곡의95백분위 변화량을 기준으로 정규화하고70ms 이상 간격인 봉우리를 센 값이다. 드럼 타격 수나 장르·악기·조성 판정이 아니다. RMS(평균 신호 크기)는 녹음 dBFS이며 음원 마스터의 LUFS가 아니다.
- BeatThis 모델의 박자 후보와 별도로, 기존07시리즈 도구의 저·중·고역 변화량에서20초 창을10초마다 옮기며50–220 BPM 반복주기를 찾는다.500Hz 변화량의2ms 시차 간격은 주변 봉우리 보간으로 보완한다. 모델은16박 간격도 함께 보아20ms 출력 간격의 영향을 줄인다. 본체 p10–p90은 중·고역이 서로 지지한20초 구간의 요약이다. 순간 BPM의 정확한 변화 곡선을 확정한 값은 아니다.
- 절반·두 배 BPM은 박자를 세는 단위의 다른 가능성이다. 모델과 독립 추정이 약126을 지지해도63을 느린 한 박으로 세는 음악적 해석을 측정만으로 배제하지 않는다.220보다 큰 두 배 값은 독립 검색 범위 밖이다.170에 가깝다는 이유로 약166.7인 다른 반복 패턴을 선택하지 않는다.
- Dancing Tears는 모델의 대표값67.42BPM을 그대로 선택하지 않은 예외다. 독립 중·고역의 강한127–132BPM 반복과126–139초 모델의131BPM 구간이 두 배 계열도 지지한다. 길이 계산 기준130.676BPM은49–184초 본체의 독립 추정 중앙값이다. 연결 후보에서는 안정된 절반 속도 모델의 간격 하나를 선택한 두 박으로 세고 실제 측정한 양끝만 사용한다. 중간 박 위치를 새로 만들지 않으며 마디 해석의 신뢰도는 중간 이하로 남긴다.
- 4·8마디 후보는4/4박자를 가정한다. 모델의 첫 박자 위치는 청음으로 확인하지 않았다. 모델 박 간격과 독립 반복주기가 맞고, 별도 기록한 불안정 구간 및 상대적 도입·끝 구간을 침범하지 않는 후보만 남긴다. 신뢰도는 중간이며 실제 자르기·겹치기 지시가 아니다. 뒤쪽 박자 누락이 있는 곡은 마지막 후보가 실제 끝보다 훨씬 앞설 수 있다.
- 170 길이 추정은 `원래 전체 곡 길이 × 대표 반복 BPM ÷170`이다. 도입·끝을 포함한 전체 길이에 곡별 고정 속도 비율 하나를 적용한 산술값이며 겹침은 없다. 원래 BPM 변동이 있으면 이 비율만으로 모든 지점이 정확170이 되지 않는다. 박자별 시간 보정·음질 승인·170 렌더링은 수행하지 않았다.
- 측정 음색 이웃은 여섯 수치를 IQR(가운데 절반이 퍼진 폭)로 맞춘 거리다. 청감상의 유사성이나 최종 순서 점수가 아니다. `Style`은 정확한 공개 곡 ID에 연결된 기존 UI 원문이며 보조 근거다. 동일 문구가 실제 같은 스타일을 보증하지 않는다.

시간축 편향과 반복주기 추정의 방향성 검사는 `tempo-timebase-audit.json`에 있다. Goodbye·Faded의 UI/PTS 시계 비율은 앞·중간·끝 모두 거의1이고, 일정 BPM 합성 입력도 창 위치에 따른 방향성 상승을 만들지 않았다. Faded의 넓은 상승 경향은 여러 추정법이 지지하지만 짧은 창의 강세 패턴은 일부 다른 값을 만들었다. 세부 순간 수치의 확신도는 이 한계를 반영한다.

선례: `work/2026-10-25-1930-wish/analyze-wish.py`, `SERIES/07-00/production/measure-corrected-beats-180.py`. 현 작업은 기존 로컬 환경과 모델을 재사용했고 설치·다운로드를 하지 않았다.
