# 07:00 — 180 BPM 재제작

## 확정 범위

- 젠의 2026-10-24 요청: 삭제한 이전 YouTube 영상을 대신할 새 영상 제작·업로드.
- 기존 선택 20곡과 번호순 유지. 선택 근거: `SERIES/07-00/input/suno-final-selection-2026-10-12.json`.
- 각 곡의 실제 박자를 측정하고 음높이를 유지하며 180 BPM으로 조정. 곡 사이의 박자 연결.
- 20곡을 2회 구성. 20→1을 포함한 39개 전환과 40개 시작 시각 확인.
- 새 썸네일은 젠이 선택·직접 제작했다. 새 업로드 제목은 아직 젠의 확인 전이다. 썸네일에 시간 숫자 없음.
- 06:30 완료물은 변경하지 않음. 이후 젠이 별도로 요청한 보관본 두 곡의 Suno 재시도만 병렬 수행했고 6번 성공·11번 거절·현재 19곡이다. 공개 영상과 보관 원본은 불변이다.

## 선례와 현재 실물

- 선례: `scripts/continuous_mix_0630.py`, `scripts/continuous_mix_0630_repeat.py`, 06:30 최종 제작 기록. 06:30의 특정 전환 청취 예외는 이 시리즈에 적용하지 않는다.
- 착수 시점의 07:00 로컬 음원·영상은 0개였다. 10월 12일 다운로드·업로드 기록은 과거 기록이며, 원래 선택의 ID와 해시는 남아 있다.
- 이전 영상 삭제는 젠의 보고다. 새 업로드는 아직 시작하지 않았다.

## 진행 단계

1. [완료] 같은 선택 ID 20개의 원본 WAV 재확보·형식·길이·새 해시 대조. 과거 해시는 동결 원장에 별도 보존하며 과거 다운로드와 바이트 일치를 주장하지 않는다.
2. [기술 검사 완료] 20곡의 박자·구간별 변동 측정과 음높이 유지 180 BPM 보정. 17번의 저음 파형 중복은 소리 자체를 바꾸지 않는 측정용 300 Hz 이상 대조로 분리했고 기존 상관·위치 일치 기준을 유지했다. 별도 박자 모델로 전곡을 측정했다. 수치 검사를 전곡 청취 승인으로 해석하지 않는다.
3. [제작·기술 검사·독립 검토 완료 / 청취 확인 전] 20곡×2회, 40개 재생 구간·39개 전환의 AAC 제작. 실제 길이 6,722.858833초. 전환 20종의 박자 차이 기준 통과, AAC의 59곳 내용·시간 검사 통과, 최종 -15.95 LUFS·-3.04 dBTP. 독립 Astra/high 오디오 검토 CLEAN(두 번째 회차 본문 20곳도 별도 대조). 전환별 16초 WAV 20개와 전체 믹스를 청취용으로 제공한다. 젠의 새 음원 청취 확인은 아직 전이다.
4. [완료] 젠이 한국 도심의 세 러너 장면을 선택하고 최종 JPG·PSD를 직접 제작했다. 최종 프롬프트·원본 PNG·PSD·JPG 네 파일을 보존한다. 과정 자료는 젠의 삭제 지시에 따라 동결 목록으로 정리한다.
5. [시작 시각 완료 / 제목 대기] 새 시작 시각 40개는 `production/continuous-180-20261024/tracklist.txt`에 기록했다. 제목 후보 작성과 젠의 제목 확인 후 최종 문안 반영은 남아 있다.
6. [대기] 4K 영상 제작, 관련 게이트와 독립 검토, 업로드·공개 확인.
7. [대기] 최종 출처·제작·게시 기록 갱신. 미디어 정리는 해당 보존 결정에 따라 별도 처리.

현재 일반 `validate`는 옛 loop 입력이 없어 실패한다. 젠의 최종 JPG를 직접 쓰는 새 완성 믹스를 발매 계약에 연결하기 전이며, 아직 source-final·upload-ready로 승격하지 않았다. 원시는 `production/continuous-180-20261024/stage-validation.json`, 오디오 검토는 `.ai/reviews/2026-10-24-0700-continuous-audio-review.md`에 있다. 옛 loop를 복원하거나 새 믹스에 `pack` 반복을 더하지 않는다.

## 증거 원칙

- 원본 다운로드와 보정본을 구분하며 과거 원본 해시를 보정본 해시로 바꾸지 않는다.
- 목표 180 BPM, 측정값, 청취 확인을 구분한다. 측정하지 못한 구간을 통과로 기록하지 않는다.
- 원본이 부족하면 같은 제목의 다른 후보로 대체하지 않는다.
- 이미 2회 구성한 완성 믹스에 `pack`으로 반복이나 재합성을 더하지 않는다.

## 확정된 영상 이미지

- 새 정적 이미지 입력: `SERIES/07-00/input/thumb.jpg`. 최종본 해시는 concept.md의 Final Artwork와 같다.
- 이전 `input/loop.png`와 예전 배치 지시 파일은 이번 제작에 사용하지 않는다. 새 영상은 아직 없다.
- 선례: 06:30에서 젠의 최종 JPG와 완성된 2회 AAC를 연결한 정적 이미지 제작 방식. 새 음원이 완성되면 이번 07:00의 실제 길이·40개 시작 시각·출처 해시로 기록한다.
- JPG의 색이나 글자를 다시 바꾸지 않는다. 4K 출력은 영상 인코딩 시 확대하며 네이티브 4K 사진으로 표기하지 않는다.
