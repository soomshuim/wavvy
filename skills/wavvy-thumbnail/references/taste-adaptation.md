# Taste principles for a static Wavvy thumbnail

Source lens: the installed Taste plugin's `design-taste-frontend` and `high-end-visual-design` skills. This reference translates their visual core to a still image; it does not invoke their web-only workflow or copy its React, animation, navigation, or component rules.

| Taste core | Thumbnail decision |
|---|---|
| Read the brief before designing | Infer the series time, listener moment, genre, mood, audience, existing assets, and user references. Write a one-line Design Read. |
| Audit a redesign's existing brand | Inspect Wavvy's real logo and at least two completed series thumbnails. Keep recognisable channel cues unless 젠 asks for a redesign. |
| Deliberate variance and density | Choose an intentional composition and a small number of text elements. Avoid repeating a previous thumbnail's scene merely because its layout was easy. Static art has no motion dial. |
| Real visual asset | Use an actual scene image or supplied photograph as the subject. Avoid fake interface elements and decorative filler. |
| Typography hierarchy | Use a short title whose size, weight, line breaks, and placement create one first read at phone-feed size. Use the real logo rather than a generated imitation. |
| Calibrated color and contrast | Derive the palette from the approved scene and series mood. Keep color treatment consistent, and give text enough separation from the image without burying the photograph. |
| Anti-template discipline | Look for generic AI faces, invented lettering, gratuitous glow, arbitrary badges, tiny captions, and repeated stock-like layouts. Correct only the issues present. |
| Preflight on the actual surface | Inspect the thumbnail at full resolution and a small phone-feed preview. Check visual balance, crop, legibility, exact copy, and subject detail before delivery. |

The 17:00 precedent put the Wavvy logo and time at upper left and a large two-line title against dark negative space. It removed the small lower caption seen on 15:00 because that caption was not useful at phone size. This is a tested Wavvy precedent, not a fixed template for every series.
