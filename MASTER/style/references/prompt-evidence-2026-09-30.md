# Suno Style Prompt Evidence — 2026-09-30

Accessed: 2026-09-30. 이 문서는 공식 설명과 Wavvy의 편집 판단을 구분한다. 사용자의 현재 모델·옵션을 확인한 자료는 아니다.

- [Suno v6 FAQ](https://help.suno.com/en/articles/13924481) (2026-09-09 수정): v6 계열은 보컬·악기·구조·분위기 등 음악 언어의 복합 설명과 여러 입력을 지원한다고 설명한다. Variety 슬라이더는 Style 입력을 조정하며 0은 태그 제어를 유지한다고 안내한다. 특정 첫 단어의 효과나 결과 정확도를 보증하지 않는다.
- [Suno v4.5 소개](https://suno.com/blog/introducing-v4-5) (2025-05-01): 감각적인 설명과 상세한 Style 지시를 지원한다고 설명한다. 과거 Wavvy의 8–10토큰 보편 상한을 뒷받침하지 않는다.
- [Suno Exclude 도움말](https://help.suno.com/en/articles/3161921) (2025-12-19 수정): Custom Mode의 Advanced Options > Exclude에 원치 않는 악기·요소 등을 입력할 수 있다고 안내한다. 8개 항목은 공식 제한이 아니라 Wavvy 내부 예산이다.
- [Suno 보컬 성별 도움말](https://help.suno.com/en/articles/10153473) (2026-09-09 수정): Custom Mode의 Vocal Gender에서 Male/Female을 선택하고 Style에서 음색을 더 설명할 수 있다고 안내한다. 이는 출력 제어 수단이지 매번 원하는 보컬이 나온다는 보증이 아니다.
- [Suno 곡 길이 도움말](https://help.suno.com/en/articles/13924929) (2026-09-09 수정): v6 계열은 단일 생성 최대 8분, 이후 Extend를 안내한다. 특정 곡의 3:20 목표가 프롬프트만으로 실현된다는 뜻은 아니다.
- [Suno 직접 가사 입력 도움말](https://help.suno.com/en/articles/2415873) (2025-12-19 수정): Custom Mode에는 사용자가 쓴 전체 가사를 넣을 수 있다. Wavvy의 짧은 prompt-only 입력은 그와 별도 선택이다.

Wavvy 판단: 읽기 좋은 자연어로 장르·그루브·보컬·악기 역할·공간·곡의 대비를 연결한다. Style 900자와 Exclude 8개는 내부 편집 예산이다. 생성 모델·옵션은 실제 사용값만 기록하고, 보컬·BPM·조성·길이·Intro는 생성 후 듣거나 측정해 확인한다.
